# Crop Expert v0.24.9 — OPT Visual + MoA Mobile

## Release scope
- Mengunci foto lokal S. exigua: gejala, imago, larva.
- Menambahkan foto lokal S. litura: gejala, imago, larva.
- Menghapus fallback ilustrasi AI Thrips dari jalur visual S. exigua/S. litura.
- Memastikan siklus hidup tetap tampil berdasarkan `life_cycle_reference` atau `life`.
- Memperbarui Cara Kerja Pestisida:
  - ilustrasi Target Sites Lepidoptera lokal,
  - layout alur 4 tahap yang terbaca di mobile,
  - detail target molekuler/proses,
  - tag kelompok IRAC,
  - tag contoh bahan aktif,
  - contoh bahan aktif pada mode of entry.
- `data/pesticide_mode_of_action_2026.json` dinaikkan ke `2026.2`.
- Versi aplikasi diselaraskan ke `v0.24.9` pada UI dan service worker.
- Menambahkan `VERSION` untuk tracking versi.

## Catatan visual
Foto Spodoptera yang ditambahkan berasal dari file yang diberikan pengguna. Foto gejala bawang digunakan sebagai visual lapangan dan tidak diposisikan sebagai bukti identifikasi spesies tunggal.

## IRAC
Konten MoA mengacu pada klasifikasi IRAC v11.5 (Februari 2026). Verifikasi terakhir: situs IRAC mencantumkan v11.5 sebagai versi terbaru yang tersedia pada Februari 2026.
