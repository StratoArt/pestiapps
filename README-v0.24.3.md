- Merapikan duplikasi ID/nama OPT dan memperbarui seluruh relasi.
- Memperkaya deskripsi, gejala, petunjuk identifikasi, kondisi pendukung, dan status kepentingan untuk OPT penting.

- Menyempurnakan tampilan detail OPT agar menampilkan Deskripsi, Petunjuk Identifikasi, Kondisi Pendukung, dan Prioritas Data.
