# Crop Expert v0.24.5 — OPT Classification

- Foto referensi publik/berlisensi ditambahkan pada OPT utama Bawang Merah dan Cabai.
- Ilustrasi AI lokal disediakan sebagai fallback visual dan diberi label jelas.
- Siklus hidup tiap OPT utama ditambahkan.
- Deskripsi, gejala/serangan, petunjuk identifikasi dan kondisi pendukung tetap terhubung.
- Sumber visual dicatat dalam `opt_visual_sources_2026.json`.
- Visual tidak dimaksudkan sebagai bukti diagnosis; identifikasi foto lapangan tetap perlu mempertimbangkan gejala, inang, lokasi, dan bila perlu konfirmasi laboratorium.


## v0.24.5 — Klasifikasi OPT
- Penyakit: Jamur, Jamur Basah, Bakteri, Virus.
- Jamur Basah menandai Oomycetes; Plasmodiophora dipertahankan sebagai catatan taksonomi khusus.
- Gulma: Rumput, Daun Sempit, Daun Lebar.
- Nama teknis/golongan tetap disimpan untuk pengguna teknis.
